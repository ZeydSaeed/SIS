## معايير القبول المختصرة لعناصر v1

- F-01/F-09/F-11: إنشاء/تعديل/إلغاء امتحان وجلسة من الويب، باختيار مادة/صف/سنة بأدوات اختيار (لا معرّفات خام)، مع رفض الخادم للحالات غير المسموحة واختبار 403 عبر المدارس.
- F-10: معاينة المستبعدين وأسبابهم قبل التسكين؛ لا تسكين مكرر (قيد DB).
- F-18/F-21: لا نشر لنطاق ينقصه نتيجة رسمية؛ نشر واحد فعّال لكل نطاق؛ السحب بسبب؛ الطالب يرى المنشور فقط.
- F-20: الحساب لا يغيّر نتيجة رسمية بصمت؛ إعادة البناء بصلاحية `results.rebuild` فقط.
