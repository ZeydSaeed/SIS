# تقرير بوابة واجهة المناهج التشغيلية

**التاريخ:** 2026-09-29  
**الحالة:** PASS WITH CONDITIONS  

## ملخص

تم إكمال واجهة تشغيلية عربية RTL للمناهج فوق العقود الخلفية الموجودة دون جداول/handlers مكررة، ودون إصلاح مخالفات Enrollment/Admission القديمة.

## ما أُعيد استخدامه

- Application Commands/Queries للمناهج والمواد والروابط والمتطلبات
- تعيين مواد التسجيل عبر `AssignEnrollmentSubjectHandler` (بوابة المتطلبات في الخادم)
- صلاحيات `curriculum.view` / `curriculum.manage`
- Window Manager الموجود (`window-registry`) — بدون إطار نوافذ ثانٍ
- كتالوج الفرع/القسم + `vocational.specializations` كاختصاص مهني

## تمييز المفاهيم (مهم)

| الواجهة | المعنى | العمود |
|---------|--------|--------|
| الاختصاص | تخصص مهني للمنهج | `curriculum.curricula.specialization_id` |
| القسم | طبقة تنظيمية وسيطة (عرض) | `organization.departments` عبر التخصص |
| الفرع | فرع المدرسة | عبر القسم ← الفرع |
| الاختصاص في التسجيل | غالباً `department_id` في شاشة التسجيل | **لا يُخلط** مع `specialization_id` للمنهج |

## الواجهة الجديدة/المكتملة

| السطح | المسار |
|-------|--------|
| قائمة المناهج + فلاتر خادم + ترقيم | `GET /curriculum` |

| تفاصيل المنهج (تبويبات) | `GET /curriculum/curricula/{id}` |
