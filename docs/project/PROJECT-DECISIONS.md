# SIS — سجل القرارات (عام)

## 0. قواعد هذا السجل

1. **الحالات:** `ACCEPTED` (معتمد للتنفيذ) · `ACCEPTED IN PRINCIPLE` (التصميم/الاتجاه فقط، لا تنفيذ) · `PROPOSED` (اقتراح لم يُعتمد) · `PENDING` (ينتظر المالك) · `REJECTED` · `SUPERSEDED BY <id>`.
2. **الموافقة على التصميم ≠ الموافقة على التنفيذ.** تنفيذ أي وحدة يحتاج قرارًا `ACCEPTED` يذكرها بالاسم.
3. **الاقتراح ليس موافقة.** كلام سابق للمساعد («أقترح…»، «الخطوة التالية…») أو ملخص محادثة لا يُعد إذنًا. الدليل = رسالة المالك أو قرار مكتوب هنا/في `EXAMIS-DECISIONS.md`.
4. موافقة على قاعدة البيانات الحية تخص العملية المذكورة فقط ولا تمتد لغيرها.
5. لا يُعاد فتح قرار `ACCEPTED` دون سبب موثق في سطر جديد (لا يُمحى السطر القديم؛ يُعلَّم `SUPERSEDED`).
